# elf-showcase-page

The public privacy notice for the elfyou Twitch extension, served with GitHub
Pages at <https://egen-co.github.io/elf-showcase-page/>. That URL is the one in
the Privacy Notice field of the extension's Version Details on Twitch.

`index.html` is a copy. The source is `privacy/index.html` in the extension's
repository (private), where it sits next to the README's "User Data" section it
mirrors. Edit it there, then copy it here — don't edit this copy directly, or
the two will drift.

`.nojekyll` tells Pages to serve the file as written instead of running it
through Jekyll.
